01 — 这一课在解决什么

把四件工具，放回各自的位置

很多读者把"吻"、MACD、背驰、中枢混成一锅粥。缠师这一课先做减法——告诉你哪些是"辅助"，哪些是"根基"。

所谓的"吻"，是和均线系统相关的，而均线系统只是走势的一个简单数学处理，说白了，离不开或然率，这和后面所说的中枢等概念是完全不同的。— 缠中说禅，2007-01-23

翻译成人话：均线和 MACD 是"辅助系统"——它们只是把价格做了滑动平均或差值，背后不带"必然性"的逻辑；而中枢是"骨架系统"——它由"至少三段次级别走势"严格构造出来，对应着资金真实的博弈结构。

所以学习顺序是：先用均线和 MACD 上手（直观、好学），再啃中枢和走势类型（晦涩、但根本）。这一课就是教你"两条腿一起走"——MACD 提供节奏信号，中枢提供结构判断。

工具
本质
能解决什么 / 不能解决什么
均线（吻）
滑动平均；看快慢线缠绕
能：看大方向、看趋势是否乏力
不能：精确给买卖点
MACD
快慢均线之差；柱子=乖离度
能：辅助判断背驰、提示动力衰竭
不能：单独定级别
中枢
三段次级别走势的重叠区
能：定级别、定买卖点（一类/二类/三类）
不能：精确预测价格
背驰
同级别两次冲击对比力度衰减
能：判断转折时机
不能：判断幅度，幅度只能"至少回到 B 段"
02 — MACD 的乖离极限

柱子伸到顶，就是身体到极限

超短走势里，MACD 柱子的"伸长高度"本身就是信号——这是缠师在本课里教的第一个具体技法。

缠师举的是 600779 水井坊 2007-01-22 的 1 分钟图，从 16.40 一路冲到 19.08。这种"1 分钟级别延伸"的极快走势，1 分钟图上甚至来不及形成背驰——价格还没"对比"完一次，下一波就已经上去了。这种时候只有一个办法：

MACD 柱子伸长，和乖离有关，大致就是走势和均线的偏离度。打开一个 MACD 图，首先应该很敏感地去发现该股票 MACD 伸长的一般高度。一旦触及这个乖离的极限，特别是两次或三次上冲该极限，就会引发因为乖离而产生的回调。— 缠中说禅

这里有一个关键的"反常识"细节。这两次的柱子面积更大（连续更久），但峰值高度反而没创新高——这就是"两次冲击乖离极限不破"。面积 ≠ 强度，缠师看的是峰值高度。

前提条件

仅限 1 分钟急涨

这种"看柱子高度"的判法，只在 1 分钟急促上升时用。其他情况下，必须配合黄白线（DIFF/DEA）一起看。

如何"标杆化"

先看一般高度

在动手前先扫一遍这只票最近的 MACD 柱子峰值——在盘整里它伸到哪儿就回；在趋势里它能伸更高，但也有极限。先把这个"极限"在心里画一条线。

03 — 一字涨停的特殊处理

连续涨停里，MACD 是失灵的

超快走势用柱子高度判，那超慢呢？连续一字涨停又是另一种"病态"，缠师给了第二套办法。

股票不断一字涨停时，由于 MACD 设计的弱点，在 1 分钟、甚至 5 分钟上都会出现一波一波类似正弦波的走势。这时候不能用背驰来看，最简单：

看 1 分钟中枢能否不断上移

中枢一直上移 → 不管它，让它涨。中枢上移结束 → 进入较大调整。

用更长周期 MACD 配合（如 30 分钟）

看 30 分钟红柱子回跌的低点：低点越来越低 → 触及 0 轴 → 稍跌破 → 再放红伸长，这就是警告信号。

判断"涨停封不住"的位置

大级别上刚好碰到阻力位 + 涨停封不住，大幅震荡就很自然。

缠师举例 600385 *ST 金泰（当年的暴涨明星）：在 2.92 涨停时，MACD 出现一点点绿柱子，然后继续涨停继续红柱子；3.28 元是前期日线高位，结果 3.22 涨停一没封住，就开始大幅震荡。

如果这种连续涨停是出现在第一段的上涨中，即使打开涨停后震荡结束、形成一定级别的中枢，往往还有新一段的上涨。必须在大级别上形成背驰才会构成真正的调整。— 缠中说禅

这一段写给"中线玩家"听：超短意义不大，关键是抓住大级别的调整不参与，其它的细节交给短线党玩去。

04 — 这一课的灵魂：标准两中枢上涨形态

把"两个中枢的上涨"拆给你看

这一段是整课最核心、最具操作性的内容——它告诉你一只"标准上涨股"在 MACD 上长什么样，让你提前知道一只股的"前生后世"。

一般来说，一个标准的两个中枢的上涨，在 MACD 上会表现出这样的形态：第一段，MACD 的黄白线从 0 轴下面上穿上来，在 0 轴上方停留的同时，形成相应的第一个中枢，同时形成第二类买点，其后突破该中枢，MACD 的黄白线也快速拉起……然后进入第二个中枢的形成过程中，同时 MACD 的黄白线会逐步回到 0 轴附近，最后开始继续突破第二个中枢，MACD 的黄白线以及柱子都再次重复前面的过程，但这次，黄白线不能创新高，或者柱子的面积或者伸长的高度能不能突破新高，出现背驰。— 缠中说禅

这一段读起来绕，但拆成 5 步就清楚了——把它背下来：

启动段：黄白线从 0 轴下方穿上来

这是趋势萌芽。价格从底部反弹，MACD 黄白线（DIFF/DEA）由负转正、爬到 0 轴之上。

第一个中枢：黄白线在 0 轴上方"横"住

价格走出第一段后回拉震荡，三段重叠形成第一个中枢；MACD 黄白线没有继续上拉，而是停留在 0 轴附近横盘——第二类买点就在这里出现。

主升段：突破中枢，黄白线快速拉起

这是最有力度的一段，所谓"走势延伸""指标钝化"都常出现在这里。一般以一个次级别背驰结束。

第二个中枢：黄白线回拉到 0 轴附近

价格在更高一层震荡构造第二个中枢；MACD 黄白线"回家"到 0 轴附近——这就是第二个"二买"的伏笔。

终结段：突破第二个中枢但黄白线/柱子创不出新高

价格再创新高，但 MACD 没跟上——背驰——这只股的"两中枢上涨"宣告结束。

这里的精华在哪？缠师不是教你"看图找背驰"，而是教你用 MACD 的形态预判结构——只要你看到第一个 0 轴横盘+第二类买点，就能预判后面还有第二个中枢、第三段、和最终的背驰。这是从"图形识别"上升到"结构预测"的关键一跃。

05 — 真金白银的实证

缠师当年点的"标准案例"，事后涨了 212%

缠师选 000572 海马股份（当时叫 ST 海马、原 0572）作为本课例子。这只票"力度厉害"，是因为它日线 + 周线双重二买，相应 MACD 也双重在 0 轴形成中枢。我们拉真实行情验证——结果价格、节点、形态全部对得上。

06 — 一个常被忽略的细节

0 轴中枢，可能不止是"日线"

这一段读上去不显眼，但实操中是个常见误区——MACD 黄白线在 0 轴附近形成的中枢，不一定就是相应级别的中枢。

必须注意，MACD 在 0 轴附近盘整以及回抽 0 轴所形成的中枢，不一定就是相应级别的中枢，而是至少是该级别的中枢。例如日线 MACD 的 0 轴盘整与回拉，至少构成日线的中枢，但也可以构成周线的中枢，这时候就意味着日线出现三段走势。— 缠中说禅

把这句话翻译成"决策树"：

日线 MACD 看到 0 轴中枢 → 至少是日线中枢

这是默认情况：日线级别一段走完，回踩形成中枢，是次级别（30 分钟）三段构造的。

如果该中枢"持续时间够长" → 升格为周线中枢

意味着日线本身已经走完三段，整个结构升一级——这时操作策略也要相应放大级别。

这就是为什么有人盯日线却"错失大调整"——他把周线级别的中枢震荡当成日线小调整来玩，结果被反复甩下车。中枢识别要"升级思考"，而不是固守你最初的级别。

判图练习：MACD 在 0 轴附近停留 4 个月，怎么算？

假设你看的是日线，MACD 黄白线在 0 轴附近横了 4 个月，期间股价反复在一个箱体内运行。请问这是日线中枢还是周线中枢？

查看答案

4 个月在日线上已经包含大量的 30 分钟三段走势——形成日线中枢是肯定的。但同时它也构成了周线级别的三段（因为 4 个月够走出 3 周以上的反复），所以这是周线级别的中枢。这时候不要再盯日线，要看周线背驰来判结束。

07 — 解盘实战：多级别综合应用

大盘 2007-01：60 分钟才是关键

缠师在课文末尾对当时的上证大盘做了一段精彩的"多级别综合判断"——把这一课所有工具放进真实战场。

缠师的判断逻辑可以归纳为四步——这就是多级别综合应用的标准流程：

  1. 先排除小级别噪音：5 分钟"刚从 0 轴上来"，根本不构成背驰条件，所以不用为它担心。
  2. 定位真正的风险级别：60 分钟可能的背驰才是杀伤力来源——"60 分钟一天才 4 根，所以还有几天可以看的"。
  3. 给出可执行的判断标准：60 分钟要不出现背驰、就要迅速拉起来；否则在这里折腾几天就会出问题。
  4. 关键支撑位作为最后防线：大盘震荡的回试，应该在 2870 上站稳。
1 分钟背驰就把机动的资金撤出来，为下次进攻当准备……而下次的买点，就要看 30 分钟等的调整情况，要综合判断，不能光一味用 1 分钟。— 缠中说禅，2007-01-26 解盘
08 — 三个工具拼在一起的买卖点

具体到操作：MACD + 中枢 → 三类买卖点

这一课的最终落地——把前面所有的工具，对应到三类买卖点。

1

第一类买点 — 同级别底背驰

价格创新低、MACD 没创新低。课文里 10:57 大盘 2720 配合 MACD 黄白未破前低，就是 1 分钟级别的一类买点。

2

第二类买点 — 一类买后的次级别回试

一类买后反弹，再次回踩但不破前低；MACD 黄白线"双回抽 0 轴站稳"。课文里下午 13:30 大盘 2771 就是 1 分钟二买。

3

第三类买点 — 突破中枢后的回踩不破

价格突破中枢上沿、回踩不再跌进中枢内。注意：1 分钟级别上几乎没有三类买（因为 1 分钟就是最低级别）。三类买更多出现在 30 分钟、日线级别。

1

第一类卖点 — 同级别顶背驰

价格创新高、MACD 没创新高；柱子面积/峰值没突破前次高。这是缠师本课主推的"标准两中枢上涨终结信号"。

2

第二类卖点 — 一类卖后反弹未过前高

顶背驰后下跌反弹，但反弹无法突破前期高点；MACD 黄白线再次靠近 0 轴时是离场窗口。

第一类买点当然比第二类低，二比三低，卖点反过来。— 缠中说禅

所以中线玩家应该三类买点上车、三类卖点离场（最高位+1-2 波的位置），不必死磕一类买的"最低点"——能拿住主升才是关键。短线机动资金则可以一类买进、二类卖出做差价。

09 — 思考题

课后留作业

  1. 乖离极限怎么定？缠师说"全凭经验"，不是柱子缩短就是背驰。那你怎么判断自己手里这只票"乖离 1.0"和"乖离 1.2"到底哪个是极限？提示：看它过去 3-6 个月每次主升时柱子峰值的分布。
  2. 0 轴附近的中枢可能升格周线。当你日线在做的中枢"持续了 4 个月"，你应该改看哪个周期？操作策略相应怎么调整？
  3. "两中枢标准上涨"是不是必然？缠师没说"一定"。如果一只票第一段上涨之后就出现顶背驰、根本没第二个中枢，怎么办？提示：要看启动段的级别和力度，弱的票本来就走不出标准形态。
  4. 实战题：000572 在 2007-01-23 当天最高 11.98 元——如果你是当天 11.50 接到货的人，应该看哪个级别的指标判断"要不要拿"？

判图练习：连续涨停打开后该怎么处理？

一只票连续 5 个一字涨停，今天涨停打开，最高摸了一下 3.28（前期日线高位），收盘 3.10。MACD 30 分钟柱子开始缩短。请问：这是顶背驰吗？该走还是该留？

查看答案

关键看是"第一段上涨"还是"已经走完两中枢"。如果这是连续涨停后的第一波打开——课文明确说"震荡结束、形成一定级别中枢后，往往还有新一段上涨"。除非你能在大级别（如周线/月线）上看到背驰，否则不该完全离场。正确动作：把机动资金（1/4-1/3 仓位）撤出来，剩余仓位等中枢形成后看新一波。

10 — 缠师本课金句

三句话定调

明白这个道理，大多数股票的前生后世，一早就可以知道了。— 关于"标准两中枢上涨"的总评
在快速市场中可以用这个，1 分钟背驰就把机动的资金撤出来，为下次进攻当准备。— 关于机动仓位的实战哲学
一定不能等什么确认，而是有卖点就卖，有买点就买，当然是根据相应的级别。— 关于操作纪律
TL;DR · 一句话总结

均线和 MACD 是"辅助"（看节奏、判乖离），中枢和背驰是"骨架"（定级别、定买卖点）；把这四件工具按"多级别综合"的方法叠起来用——一只票从一买到主升到顶背驰的"前生后世"，能在它走完第一段时就大致看清。
