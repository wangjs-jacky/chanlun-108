线段划分标准

把"线段被另一段破坏"这句模糊的话，精确成一套可机械执行的判定规则——缠论几何体系的最后一根承重柱。

01 — 这一课要解决什么

线段"什么时候算结束"，第一次有了精确答案

在第 65 课之前，缠师只说过一句模糊的话："线段破坏的充要条件就是被另一个线段破坏"。这一课，把它精确化。

前面的课已经定义了 分型、笔。一笔之上的"段"该怎么数？以前只能凭感觉——"看起来像一段就是一段"。但凭感觉的东西，十个人有十种数法，整个几何体系就站不住脚。

本课的目标只有一个：给"线段在哪里结束"一个没有任何歧义的、可机械执行的判定规则，让任意一张走势图都能唯一地被划分成线段的连接。一旦做到这一点，中枢、走势类型、买卖点这套递归体系才有干净的零件可用。

本课，就是把前面"线段破坏的充要条件就是被另一个线段破坏"精确化了。因此，以后关于线段的划分，都以此精确的定义为基础。— 缠中说禅

读这一课的姿势：抠定义、按顺序、别跳步。缠师自己都说"这个定义有点复杂"——把"特征序列 → 标准特征序列 → 顶/底分型 → 第一种 / 第二种情况"这条逻辑链一步步搞清楚，否则"一定晕倒"。

02 — 准备 · 笔的 S/X 序列

先把"线段"拆成笔的字母串

缠师用两个字母给笔编号：S = 向上笔（Shang，上）、X = 向下笔（Xia，下）。

任意一条线段，要么从一根向上笔起步，要么从一根向下笔起步——只有这两种。以"向上笔开头"的线段为例，它一定长这样：

向上笔开头的线段 = S1 X1 S2 X2 S3 X3 … 上下交替，无穷接龙

简写就是 S1 X1 S2 X2 … Sn Xn。这套字母串就是分析线段的最小语言——后面所有判断，都是在这串字母上做的。

03 — 关键发明 · 特征序列

只盯"反方向"的那几笔——这就是特征序列

缠师做了一个反直觉的关键动作：要分析一条向上的线段什么时候结束，不要去看那些向上笔（S），而要去看夹在中间的向下笔（X）。

原因藏在缠师那句"容易证明"里：

容易证明，任何 Si 与 Si+1 之间，一定有重合区间。而考察序列 X1 X2 … Xn，该序列中，Xi 与 Xi+1 之间并不一定有重合区间，因此，这序列更能代表线段的性质。— 缠中说禅

翻译：一条向上的线段里，相邻两根向上笔（S1 和 S2）一定会"打架重叠"在一起——所以盯它们看不出有用信息；而相邻两根向下笔（X1 和 X2），它们之间可能有重叠也可能没重叠，这种"有没有重叠"的变化，正好用来判断线段是否走完了。

定义

特征序列

以向上笔开始的线段：把所有向下笔串起来 = X1 X2 X3 …，这串就是该线段的特征序列。

定义

反过来同理

以向下笔开始的线段：把所有向上笔串起来 = S1 S2 S3 …，就是它的特征序列。

记住口诀：线段往上走，看向下笔；线段往下走，看向上笔。永远盯反方向那串。

特征序列两相邻元素间没有重合区间，称为该序列的一个缺口。— 缠中说禅

"缺口"是这一课的另一个核心词——后面区分两种情况，就靠它。缺口 = 反方向那串里，前后两根笔的价格区间没碰上、中间有空。这跟 K 线图上常说的"跳空缺口"是同一个意思，只是对象换成了"笔"。

04 — 把特征序列变"干净"

标准特征序列：把每一笔当成一根 K 线，再处理包含

原始的特征序列还有歧义，需要做一次"标准化"，方法和第 62 课处理 K 线包含关系一模一样。

关键的认知翻转——缠师让你把特征序列里的每一根"笔"，当成一根"K 线"来看：

视角切换

一笔 → 一根"虚拟 K 线"

每根笔有起点价、终点价 → 自然就有高点和低点，跟一根 K 线没区别。X 笔向下，它的高点是起点（顶分型处），低点是终点（底分型处）。

复用旧规矩

包含关系怎么办

两根"虚拟 K 线"互相包含时 → 按第 62 课的合并规则：向上时取高高低高，向下时取低低高低。

经过非包含处理的特征序列，成为标准特征序列。以后没有特别说明，特征序列都是指标准特征序列。— 缠中说禅

之后所有判断都在标准特征序列上做。在它身上找顶分型 / 底分型——方法也和 K 线找分型一样，但有一条不能搞反的规则：

↑

向上笔开头的线段 → 只找顶分型

你要确认的是"上涨走完了没"，所以在 X 笔（特征序列）里找顶分型，那个高点可能就是线段终点。

↓

向下笔开头的线段 → 只找底分型

你要确认的是"下跌走完了没"，所以在 S 笔（特征序列）里找底分型，那个低点可能就是线段终点。

到这一步，定义铺垫终于齐了。接下来是这门课的"心脏"——两种情况的判定。

05 — 心脏 · 两种情况

关键一刀：分型的"前两根"之间有没有缺口

缠师把所有线段结束的图形，按一个细节切成两类——分型里的第一元素和第二元素之间，有没有特征序列的缺口。

情况 1 · 无缺口
情况 2 · 有缺口
判定条件
什么时候算线段结束
实战含义（人话）
情况 1
无缺口
特征序列顶分型中，第一元素与第二元素之间不存在缺口（两笔有重叠）
该顶分型出现的那一刻，线段就结束，顶分型的最高点即线段终点。不用再等，干净利落。
情况 2
有缺口
特征序列顶分型中，第一元素与第二元素之间存在缺口（两笔不重叠、中间断开）
顶分型先不算数。要等从那个最高点开始的反方向新线段的特征序列，也走出底分型，原顶分型才被追认。
强调，在第二种情况下，后一特征序列不一定封闭前一特征序列相应的缺口，而且，第二个序列中的分型，不分第一二种情况，只要有分型就可以。— 缠中说禅

这句话要拆开看，三个坑都藏在里面：

①

第二种情况下，缺口可以一直留着

新线段走出来之后不必把那个缺口补上。很多人以为"缺口不补就不算"，错。

②

新序列里的分型，怎么样都行

反方向那条新线段的特征序列里出现底分型时，它自己是情况 1 还是情况 2 都无所谓——只要"有底分型"就够，立刻就能反过去追认原顶分型。

③

底分型 vs 顶分型是对称的

上面整段把"顶分型"换成"底分型"、"最高点"换成"最低点"，就是以向下笔开始的线段划分。逻辑完全镜像。

上面右上角那一串"顶分型后的新特征序列"——画了个底分型出来——就是情况 2 必须出现的"追认信号"。没等到它，线段就还没死。

06 — 一张图把流程穿起来

判一条向上线段是否结束 · 四步法

把上面的定义压缩成一条流水线，下次实战照着走就行。

  1. 圈出当前向上线段的所有 X 笔（向下笔），按时间顺序串起来 = 原始特征序列。
  2. 非包含化：把相邻 X 笔当 K 线看，遇到包含关系就按"向下方向合并"——得到标准特征序列。
  3. 在标准特征序列里找顶分型。没有 → 线段还没结束。有 → 进入第 4 步。
  4. 看顶分型的第一、二根元素之间：
    　• 没缺口 → 情况 1，顶分型最高点即线段终点，当场成立。
    　• 有缺口 → 情况 2，盯住从那个最高点开始的下行新线段；等它的特征序列里出现底分型，原顶分型才被追认。

向下线段同理，把"顶分型"换成"底分型"、"X 笔"换成"S 笔"、"最高点"换成"最低点"即可。

08 — 判图练习

动手判一判

三道题，把上面的判定规则在脑子里走一遍。

练习 1：一条以向上笔开头的线段，它的特征序列应该串哪几根笔？

（提示：盯反方向）

查看答案

串所有向下笔（X 笔）：X1 X2 X3 …。向上笔（S 笔）不参与特征序列。口诀："线段往上走，看向下笔"。

练习 2：在标准特征序列里数出一个顶分型，发现它的第一根和第二根元素之间隔了一大段没碰上，能立刻判定原线段结束吗？

（提示：缺口 → 情况几）

查看答案

不能立刻判定。这是情况 2——有缺口。必须再等：从顶分型最高点开始的反方向新线段，其特征序列也走出一个底分型，原顶分型才被追认。否则原线段尚未结束。

练习 3：情况 2 下，等到了新线段特征序列的底分型，但那个底分型自己也带缺口（也是情况 2），算不算数？

（提示：原文那句"不分第一二种情况"）

查看答案

算数。缠师明确说："第二个序列中的分型，不分第一二种情况，只要有分型就可以"。新序列里的底分型不需要再追究自己是情况 1 还是情况 2，只要存在就足以追认原顶分型。

09 — 思考题

再往深想一层

这几题帮你把"线段划分"和后面的中枢、走势类型接上。

  1. 为什么相邻两根同向笔（S1 与 S2）一定有重合，而相邻两根反向笔（X1 与 X2）不一定有重合？想清楚这个，"特征序列为什么必须看反方向"这件事就通了。
  2. 情况 1 和情况 2 的本质区别，是不是"动能强度"的差异？情况 2 的缺口往往意味着原方向最后一击非常凶猛，所以才"打出空"——这对实战中识别"假反转 vs 真反转"有什么启示？
  3. 有了精确的线段划分，下一步缠师就要讲走势中枢的精确定义（第 68 课起）。线段是中枢的"零件"，本课的规则不严，整个中枢理论会散架。你能想出一两个"线段没数清"会导致"中枢误判"的具体例子吗？
  4. 同一张走势图，按本课规则划线段是唯一的，但日 K / 30F / 5F 上的线段并不相同。这就涉及级别——你打算用什么周期作"本级别"判断你常做的票？
一句话总结

把线段拆成 S/X 笔串，盯反方向那串当特征序列，处理掉包含关系得到标准序列；在里面找顶/底分型，看分型前两根有没有缺口——无缺口当场成段，有缺口必须等新线段的特征序列走出反向分型来追认。这就是缠论里线段划分不可再细化的唯一标准。
