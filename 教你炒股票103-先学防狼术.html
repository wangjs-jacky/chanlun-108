先学防狼术

学屠龙术之前，先用 MACD 0 轴这一条最傻瓜的纪律，把自己挡在大跌之外。

原文 2008-03-19 类型 风险纪律 关键词 MACD · 0轴 · 空头主导 · 远离市场
↓ 向下滚动，逐条拆解
01 — 屠龙 vs 防狼

先别想着抓大牛，先别被大盘"侵犯"

这一课不教你怎么赚钱，只教你怎么在大跌里不死。

缠师写这课的背景：大盘从 5522 点一路砸到 3000 多点，很多人却还在嫌课程"太慢"、嫌中枢级别没学到。缠师的回答非常直接——你连防狼术都不过关，谈什么屠龙术。

在没彻底学会下面所说的防狼术之前，你也别研究什么中枢、级别。
有了这防狼术，至少不会被大盘严重侵犯，也不会在大盘大跌时鬼哭男嚎。 — 缠中说禅

所谓"防狼术"，就是一条最简单、最傻瓜、不需要任何技术功底就能执行的纪律——它解决的是"什么时候必须空仓远离"这件事，比"什么时候买"还重要。

02 — 核心纪律

MACD 0 轴：多空主导的分水岭

整套防狼术只有一句话，背下来即可。

就一个最简单 MACD 指标，0 轴分为多空主导。
一旦 MACD 指标陷入 0 轴之下，那么就在对应时间单位的图表下进入空头主导，而这是必须远离的。 — 缠中说禅

翻译成操作：

MACD 黄白线位置
市场状态
动作
0 轴之上
多头主导
可以正常操作、可以介入
0 轴之下
空头主导
彻底离开，直到重新站住 0 轴再说

缠师明确举了大盘 60 分钟图的例子：5200 点 MACD 跌破 0 轴并反抽确认后，一直到 3000 多点都在 0 轴下晃悠——这段杀伤力，凡是没遵守这条纪律的，全都体验过。

03 — 周期选择

哪一根 MACD？看你自己的能力

这条纪律涉及"看哪个周期"的问题，缠师把选择权交给你。

同一只票，1 分钟 MACD 经常一会儿 0 轴下、一会儿 0 轴上——如果按 1 分钟操作，你会被来回打耳光。所以必须根据自己的能力，先选定一个"最低时间周期"作为防狼术的判定级别。

大资金 / 慢节奏

日线 / 60 分钟

反应慢、信号少，但极少出错。被套时间长，但避开真正的大跌。

中等灵活度

30 分钟

缠师课文里默认的常用周期之一。在跌破 0 轴后必须撤离。

短线高手

5 / 15 分钟

反应快但信号多，需要承受更频繁的"假信号"。能力不够别用。

技术派

背驰介入

0 轴下也可以在背驰时介入——但这是最高要求，"傻瓜化"的人不要学。

一切都要傻瓜化。如果你连 MACD 黄白线是否 0 轴以下都看不懂，
那就彻底离开这个市场吧——地球很危险，回火星去吧。 — 缠中说禅
04 — 实战示例

0 轴受阻 → 探底，是机械式信号

课文后半部分用 3780 点保卫战，演示了"防狼术"如何在当下被实时执行。

3 月 21 日，缠师给出短线生命线 3780 点。理由就是机械的：

A

站住 3780 点 → 30 分钟 MACD 突破 0 轴

对应 60 分钟图向 0 轴冲击，走势上往上再上攻一段，反弹独脚成立。

B

站不住 3780 点 → 30 分钟 MACD 0 轴受阻

形成"0 轴受阻再回跌"的标准空头形态，大盘必再次探底。

C

3 月 24 日跌破 3780 点 + 第三类卖点

跌破后两次反抽上不去 → 确认跌破有效；下午 2 点第三类卖点成立 → 跌幅明显加大。"一切都极端技术化"。

05 — 月线视角

大行情的母条件：月 MACD 回到 0 轴附近

把"0 轴纪律"放大到月线，就得到了"下一轮真正大行情"的入场许可。

课文中的"2008 年行情再展望"，缠师把同一把尺子用在月线上：

从最直观的技术上说，下一轮真正的大行情，
必须等到月 MACD 回到 0 轴附近才有可能展开。
期间，都是一些小打小闹的走势。 — 缠中说禅

这同样是防狼术的延伸：

  • 月 MACD 刚刚死叉，硬向上攻击 → 最好结果只是月线双头，其后对应更大幅度下跌；
  • 年线走平后大盘还不能站回年线 → 一旦年线转头向下，才是真正大调整的开始；
  • 月 MACD 没回到 0 轴附近之前，所有反弹都是"小打小闹"，别用屠龙术的仓位去博。

课末还顺手给了一条大市道里的个股逻辑："长跑选手的坟墓，短跑选手的天堂"——大调整中，低价 + 重组 + 题材是不变的主题，绩优股有极大的中长线业绩压力。这条逻辑也建立在防狼术之上：大盘 0 轴下，谁拿长线谁吃亏。

06 — 一句话纪律卡

把这张卡贴在屏幕上

六条可执行的"防狼术清单"，看不懂中枢级别也能立即用。

1

选定一个最低周期

30 分钟或 60 分钟最常用。这是你做防狼术的"判定级别"。

2

看 MACD 黄白线相对 0 轴位置

不是看红绿柱，是看 DIF/DEA 两根线是否在 0 轴上方。

3

0 轴下 = 空头主导 = 远离

整个市场或这只股票，彻底离开。不管它怎么反抽。

4

0 轴下"受阻回落"是卖出信号

MACD 冲到 0 轴附近又回头 → 对应级别要再下一段。

5

站稳 0 轴之后才能重新介入

突破 0 轴 + 反抽确认不破 = 多头主导回来了。

6

月 MACD 回 0 轴 = 重大行情入场许可

没回到之前，所有反弹都是小打小闹，别下重仓。

本课核心：把"MACD 0 轴"当作多空分水岭，是缠论里最低门槛、最不需要解释的风控纪律。
它救不了你赚大钱，但能救你不被大盘"严重侵犯"。
