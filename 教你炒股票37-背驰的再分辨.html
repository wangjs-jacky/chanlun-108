01 — 这一课在干什么

背驰这词被滥用了，缠师亲自来收口

前面 15、24、25、29 几课讲过背驰、画过示意图，看起来该懂的都懂了。但缠师 2007-03-16 又专门写一篇——为什么？

因为在那个最经典的 a+A+b+B+c 趋势结构里，绝大多数读者还是会犯这些错：

  • 结构看起来像 a+A+b+B+c 就喊"有背驰"，忘了先问"这是趋势吗"；
  • 把 A、B 不同级别的"震荡套小段"也叫做 a+A+b+B+c；
  • c 段没创新高/新低就喊"上涨结束"了；
  • c 段是小级别（比如带连续缺口的 1 分钟），却被当成次级别的标准背驰；
  • 看到 c 段创新高就直接挂"背驰"，不去看 c 内部结构是不是次级别趋势。
背驰问题说过多次，但发现还有很多误解。不妨用最典型的 a+A+b+B+c 为例子，把一些经常被混淆的细节进行说明。— 缠中说禅 · 第37课开篇

这一课的产出不是新概念，是六条"是 / 不是趋势背驰"的判别铁律，把可能误判的边界全部贴上警示标签。学完之后，再看任何"看起来像 a+A+b+B+c"的图，你都能立刻判断——这是真趋势背驰，还是其实只是盘整里的一次摆动。

02 — 先复习这套符号

a+A+b+B+c 到底说的是什么

在往下走之前，必须把这套符号读懂——否则后面六条铁律全是天书。

标准的二中枢上涨趋势 · 缠师符号速查

a = 进入 A 之前的一段同级别次级别走势（"启动段"）；
A = 第一个走势中枢；
b = 连接 A 和 B 的次级别走势（"中间换乘段"）；
B = 第二个走势中枢，和 A 同级别；
c = 离开 B 创新高/新低的最后一段（"冲刺段"，背驰就发生在这里）。

三句话记牢这套符号：

  1. a / b / c 都是次级别的走势——级别比 A、B 低一档（如 A、B 是 5 分钟中枢，则 a/b/c 是 1 分钟级别的走势）。
  2. A、B 是中枢，必须同级别——这是 a+A+b+B+c 被叫做"趋势"的硬性条件，下面铁律 #1 会反复打这条。
  3. "c 创新高/新低"是背驰判断成立的必要条件——铁律 #3 专门讲。

⚠️ 缠师课文里出现的 GG1/ZG1/ZD1/DD1 等符号是中枢的内部坐标：GG=最高点、ZG=上沿、ZD=下沿、DD=最低点。第 25 课已详细解释，这里不再展开。

04 — 六条铁律

什么时候才能说"a+A+b+B+c 出现背驰"

这是本课的真正主菜——六条判别铁律，按缠师原文顺序逐条剥开。每一条都贴着一种常见误判。

铁律 #1 · 没有趋势，没有背驰

结构必须是真正的趋势

不是任何 a+A+b+B+c 形式都有背驰——必须先是一个趋势。趋势的硬条件：A、B 是同级别中枢。

如果 A 的级别比 B 大，那 a+A+b+B+c 就退化成 a+A+(b+B+c)——a 和 (b+B+c) 不过是围绕大中枢 A 的两段小级别波动，整段是盘整而不是趋势。这时谈"趋势背驰"是错的——最多只能谈盘整背驰。

判别 checklist

  1. 把 A、B 各自的级别标出来（如"5 分钟中枢"）。如果两者级别不同 → 不是趋势，跳过背驰判断。
  2. 同时要确认：A 之后到 B 之前的 b 段 在级别上不能大于 c。否则结构同样退化。
  3. 检查 A、B 的中枢区间是否同向递进——上涨趋势 B 在 A 上方且不重叠，下跌趋势 B 在 A 下方且不重叠。
铁律 #2 · c 必须是次级别

c 至少包含 B 的一个第三类买卖点

c 必然是次级别的走势——也就是说，c 至少包含对 B 的一个第三类买卖点。否则 c 就只是 B 中枢的小级别波动，那是盘整背驰的问题，不是趋势背驰。

还有一条容易忽略：b 可以小于次级别（最极端是连续缺口式的"一根冲过去"），但b 在级别上不能大于 c。如果 b 是次级别，而 c 出现连续缺口，c 就算没完成最终也延续成次级别——这种情况下 c 背驰的可能性极小，反而要警惕最弱走势。

力度最大的就是连续的缺口，也就是说，b 在级别上是不能大于 c 的。如果 b 是次级别，而 c 出现连续缺口，即使 c 没完成，最终也延续成次级别，但 c 是背驰的可能性就很小了——就算是，最终也要特别留意，出现最弱走势的可能性极大。— 缠中说禅
铁律 #3 · c 必须创新高 / 新低

不破前高/前低就没有"背驰"两个字

如果 a+A+b+B+c 是上涨，c 必须创出新高；如果是下跌，c 必须创出新低。

否则——就算 c 包含 B 的第三类买卖点，也只能用盘整背驰的方式判断这段围绕 B 的次级别震荡，不能上"趋势背驰"这个名分。

铁律 #3 示意：c 创新高 vs c 不创新高

左边 c 创出新高，可以谈"a+A+b+B+c 趋势背驰"；右边 c 起涨却没破前高，本质是 B 中枢的次级别震荡——只能用盘整背驰来判断。两者用法不同，下手力度也不同。

铁律 #4 · c 内部至少两个次级别中枢

c 内部本身要是一段次级别趋势

对 c 的内部进行分析：由于 c 包含 B 的第三类买卖点，c 至少包含两个次级别中枢——否则满足不了"次级别离开后次级别回拉不重回中枢"的第三类买卖点条件。

这两个次级别中枢构成一个次级别趋势，是最标准最常见的情况。换句话说：c 段在内部又是一个 a'+A'+b'+B'+c' 的小一级版本。

铁律 #5 · 区间套

大背驰套小背驰，定位精度倍增

既然 c 内部又是次级别趋势，那就可以继续套用 a+A+b+B+c 的形式分析这个小趋势的背驰——形成类似 区间套 的状态。

实战意义：大级别上看出"a+A+b+B+c 背驰要来了"，落到小级别上还能再判一次"a'+A'+b'+B'+c' 的小背驰"——两层背驰共振的那一刻，就是精度最高的入场/离场点。

铁律 #6 · 多义性 ≠ 含糊性

多个角度可以并行，但不能用一个角度否定另一个

缠师在原文里特意警告了一种"多义性的滥用"：

对于最后一个中枢 B 而言，趋势背驰与盘整背驰有很多类似的地方——可以用多义性把 b、c 当成 B 的次级别波动。但同时也必须保留"a+A+b+B+c 是趋势且 A、B 级别相同"这个角度，不能只剩盘整角度而忘了趋势角度。

多义性不是含糊性——不是怎么干怎么分都可以，这是必须不断反复强调的。— 缠中说禅

08 — 常见错误

三个最容易踩进去的陷阱

陷阱 A

"看起来像 a+A+b+B+c"就喊背驰

新手最常犯：图上一眼看到三段五段就开始数 a、b、c。正确做法：先确认是趋势，再确认 A、B 级别一致，再看 c 是否破前高/低——三关全过才能数背驰。

陷阱 B

把"c 单中枢震荡"当背驰

c 段只跑出一个小中枢就回头，这其实是 B 内部震荡，不是 c 背驰。要等 c 走出至少两个次级别中枢、并形成 B 的第三类买卖点之后，才有资格谈背驰。

陷阱 C

多义性"和稀泥"

看到走势既能套盘整也能套趋势，就含糊地说"两边都对，无所谓"。错——缠师明确：多义性允许多角度并行分析，但每个角度内部必须严格自洽，不能用一个角度否定另一个。

破解口诀

"先趋势、后新高、再两中枢"

看到疑似 a+A+b+B+c：第一步问"A、B 同级吗？"——否则不是趋势；第二步问"c 破前高了吗？"——否则用盘整背驰；第三步看"c 里有两个次级中枢吗？"——否则再等。

09 — 判图练习

动手判断：这是不是 a+A+b+B+c 背驰？

练习 1：5 分钟图上，看到一个 a+A+b+B+c 结构，但 A 是 5 分钟中枢、B 是 1 分钟中枢，c 创了新高。这叫"5 分钟趋势背驰"吗？

查看答案

不叫。A、B 级别不同，整段不是 5 分钟趋势，而是退化成"围绕 5 分钟中枢 A 的小级别震荡"——按铁律 #1 退到盘整背驰处理。

练习 2：30 分钟图上，A、B 都是 30 分钟中枢，c 段拉了一根冲过前高，但 c 内部只能看到一个小中枢就结束了。能判背驰吗？

查看答案

不能。c 内部只有 1 个次级别中枢、不构成次级别趋势——按铁律 #4，c 还在 B 的影响范围内，没法跟 b 比较力度。要等 c 内部走出 2 个次级别中枢并形成 B 的第三类买卖点之后才有资格谈背驰。

练习 3：下跌趋势 a+A+b+B+c，c 段没破 a 之前的低点，但 MACD 绿柱明显短了——这算背驰吗？

查看答案

不算"趋势背驰"。按铁律 #3，c 没破新低就没有趋势背驰的资格——MACD 绿柱缩短只能作为盘整背驰的辅助参考，名分上不能上"a+A+b+B+c 背驰"这个抬头。

练习 4：大级别 5 分钟看到一段 a+A+b+B+c 背驰准备成立，小级别 1 分钟同时也看到 a'+A'+b'+B'+c' 背驰准备成立——这叫什么？

查看答案

区间套。两层背驰共振、精度倍增——这正是铁律 #5 的核心实战价值，是缠师推荐的"最精确入场/离场时机"。

10 — 思考题

课后留作业

  1. 缠师强调"多义性不是含糊性"。请举一个例子说明：同一段走势如果只用"盘整角度"看是一种结论，加上"趋势角度"后结论被丰富，但两个角度并不矛盾。
  2. 为什么 c 段的内部分析能形成"区间套"？这个特性对"判断真实背驰位置"在精度上提供了什么数量级的提升？
  3. 如果 b 段意外出现连续缺口拉升（即 b 突然变得非常强），按本课规则，对 c 段是否能背驰有什么影响？为什么"最弱走势"的可能性反而升高？
  4. 把第 27 课"盘整背驰"和本课"趋势背驰"放在一起对比，列出三条最重要的区分点。
  5. 翻一张你自己最近的实战图，按本课六条铁律逐条打钩——找出你过去是否在哪一条上有过误判。
